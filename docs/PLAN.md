# План выполнения курсовой работы

Тема: «Настройка и администрирование платформы для автоматического создания резервных копий данных».

Решение пользователя: разработать самостоятельно только панель управления. Весь механизм резервного копирования строится на готовых PostgreSQL/BorgBackup/borgmatic. Самостоятельный брокер, worker, формат архива или алгоритм восстановления не разрабатываются.

- [x] Выбраны готовые инструменты и определены роли пяти контейнеров.
- [x] Создана собственная панель с входом, правами и CRUD заданий.
- [x] Реализована публикация настроек borgmatic и расписаний cron.
- [x] Добавлены команды ручного копирования, проверки и восстановления только в отдельную БД.
- [x] Добавлены шифрование репозитория, политика хранения и защита от одновременных запусков.
- [x] Подготовлены Dockerfile, Compose и начальные тестовые данные.
- [x] Подготовлена автоматическая интеграционная проверка восстановления.
- [x] Workflow CI реально прошёл в GitHub Actions: тесты, сборка и копирование/восстановление в Compose.
- [x] Подтверждён реальный цикл копирования и восстановления в Docker.
- [x] Подтверждена сохранность данных, настроек и архивов после пересоздания всех пяти контейнеров.
- [x] Подтверждено автоматическое срабатывание cron по времени.

## Следующие этапы

1. Сохранить скриншоты нового облачного стенда, двух узлов Swarm и успешного workflow. Локальные скриншоты уже предоставлены пользователем.
2. Написать главы по фактически выполненным действиям и сформировать пять собственных схем.
3. Подготовить презентацию, оригинальность, подписи и комплект сдачи.

## Облачный этап

- [x] Два Ready/Active узла с отдельными Docker Engine внутри одного VPS; учебная оркестрация без отказоустойчивости физического хоста.
- [x] Пять сервисов распределены между узлами: панель и scheduler на manager, restore-db на worker.
- [x] Настроены Docker secrets/configs и зашифрованная overlay-сеть.
- [x] Подключены GitHub и GHCR; полный CI/CD прошёл до успешного восстановления на VPS.
- [x] Проверены облачный HTTP-вход и автоматическая замена остановленной задачи Nginx.
- [x] Независимый снимок зашифрованного репозитория и ключевого материала сохранён на компьютере и проверен Borg. Копия однократная, автоматической внешней выгрузки пока нет.
- [x] Подтверждён запуск облачного cron по времени.

## Как распределить текст

Глава 1: виды копий, согласованность БД, RPO/RTO, анализ Borg/borgmatic, Restic и другого выбранного аналога, сформированные требования.

Глава 2: выбор готового решения, архитектура, схема сети, хранилище, права, политика хранения, схема запуска и восстановления.

Глава 3: сборка образов, запуск контейнеров, настройка панели, автоматическое копирование, проверка архива, восстановление, сравнение данных, кластер и CI/CD после их выполнения, инструкции.

Не утверждать, что копирование проверено, пока не выполнен `smoke_backup`. Не подменять доказательство восстановления наличием файла архива или успешным модульным тестом.
