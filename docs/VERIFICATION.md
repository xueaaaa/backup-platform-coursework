## Найденная и устранённая ошибка

При первой интеграционной проверке borgmatic не находил существующий дамп. Переход с Borg 1.2.4 на закреплённый Borg 1.4.5 сам по себе ошибку не устранил. Диагностика показала: borgmatic 1.9.14 сопоставляет исходный порт дампа с `--original-port`; отсутствие этого параметра не совпало с явно заданным в конфигурации портом `5432`.

В адаптер добавлен `restore --original-port 5432`. Этот параметр выбирает исходный дамп; назначение восстановления по-прежнему определяется `restore_hostname: restore-db` и `restore_port: 5432`. Успешность исправления подтверждена реальным полным циклом, а не только тестом парсера.
